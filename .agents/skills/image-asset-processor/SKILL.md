# Image Asset Processor Skill

Use this skill when processing UI assets, mascot illustrations, icons, and graphics generated by Nano Banana or imported into the project to create clean transparent background PNGs and optimized web/native formats.

## Capabilities

1. **Background Removal & Transparency**:
   - Converts solid color backgrounds (pure white `#FFFFFF`, chroma green `#00FF00`, magenta) to transparent alpha channels.
   - Floodfills background transparency from edges/corners without disturbing inner white/colored elements.
2. **Format Conversion & Optimization**:
   - Optimizes PNG, WebP, JPEG, and icon assets for mobile and web apps.
3. **Resizing & Aspect Ratio Adjustments**:
   - Scales icons for iOS/Android density buckets (@1x, @2x, @3x).

## Helper Script

Run `.agents/skills/image-asset-processor/scripts/make_transparent.sh <input_image> <output_png> [color_or_mode] [fuzz_percent]`

### Examples:

- Turn pure white background transparent:
  ```bash
  .agents/skills/image-asset-processor/scripts/make_transparent.sh assets/icon.jpg assets/icon.png white 10%
  ```
- Turn green screen background transparent:
  ```bash
  .agents/skills/image-asset-processor/scripts/make_transparent.sh assets/mascot.png assets/mascot_transparent.png '#00FF00' 15%
  ```
- Auto-floodfill transparency from top-left corner:
  ```bash
  .agents/skills/image-asset-processor/scripts/make_transparent.sh assets/badge.png assets/badge_transparent.png corner 15%
  ```
