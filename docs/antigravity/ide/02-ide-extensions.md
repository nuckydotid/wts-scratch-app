# Antigravity IDE Extensions: VS Code, JetBrains, Visual Studio, Zed & Xcode

Comprehensive installation and setup guide for Antigravity extensions across all supported major code editors.

---

## 1. Visual Studio Code

Bring Antigravity into VS Code with full side panel chat, inline diffs, and Supercomplete.

### Installation

1. Open the **VS Code Extensions Marketplace** (`Ctrl+Shift+X` or `Cmd+Shift+X`).
2. Search for `Google Antigravity` and click **Install**.
3. Click the Antigravity icon in the Activity Bar to sign in with your Google account.

---

## 2. JetBrains IDEs (IntelliJ, PyCharm, WebStorm, GoLand, CLion, Rider)

Supports all JetBrains IDEs version **2026.2.1+**.

### Installation

1. Open **Settings / Preferences > Plugins**.
2. Search for `Google Antigravity` under the **Marketplace** tab.
3. Install and restart the IDE.
4. Access the **Antigravity Tool Window** on the right sidebar.

---

## 3. Visual Studio (Windows)

Bring agentic engineering into C#, C++, and .NET enterprise solutions.

### Installation

1. Open **Extensions > Manage Extensions** in Visual Studio.
2. Search for `Antigravity for Visual Studio (Preview)`.
3. Install and restart Visual Studio.

---

## 4. The Zed Editor

High-performance Rust-native integration for Zed.

### Installation

1. Open the Zed Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`).
2. Type `extensions: install extension` and select `antigravity`.

---

## 5. Apple Xcode

Native agentic development for macOS, iOS, iPadOS, watchOS, and visionOS developers.

### Installation

1. Download the Antigravity Xcode Companion from [antigravity.google/docs/ide/extensions/xcode](https://antigravity.google/docs/ide/extensions/xcode).
2. Enable the extension in **System Settings > Extensions > Xcode Source Editor**.
