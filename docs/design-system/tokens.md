# Design System Tokens

Detailed design tokens reference for `@repo/worktrees-studio-ds`.

## Color Palette (Semantic Tokens)

- `primary`: Default brand color for key CTAs and highlights.
- `secondary`: Subdued action color.
- `success`: Positive states, confirmations, and paid statuses.
- `warning`: Pending approvals, alerts, and due date notices.
- `danger`: Destructive actions, errors, and urgent warnings.
- `default`: Neutral surfaces, borders, and body text.

## Typography Scale

- `text-xs`: Microcopy, timestamps (12px).
- `text-sm`: Secondary descriptions, form helper text (14px).
- `text-base`: Body standard text (16px).
- `text-lg`: Card titles, subheadings (18px).
- `text-xl`: Section headers (20px).
- `text-2xl`: Screen titles (24px).

## Spacing & Radii

- Spacing: 4px grid (`gap-1` = 4px, `gap-2` = 8px, `gap-4` = 16px, `gap-6` = 24px).
- Border Radii: `rounded-sm` (4px), `rounded-md` (8px), `rounded-lg` (12px), `rounded-full` (9999px).
