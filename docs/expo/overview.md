# Expo SDK 57 Overview & New Architecture

Expo SDK 57 brings full support for React 19, React Native 0.86 with New Architecture enabled by default, and Turbomodules.

---

## 1. Key Capabilities in SDK 57

- **React 19 Core**: Full compatibility with React 19 concurrent features and form action hooks.
- **New Architecture Default**: Fabric renderer and Bridgeless JavaScript execution.
- **Expo Router v57**: Typed routes, dynamic segment matching, and native stack headers.
- **Expo Modules Core**: High-performance C++ and Swift/Kotlin native module development with auto-linking.
